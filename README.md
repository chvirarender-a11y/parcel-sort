# 丰收小镇 Harvest Town（暂定名）

竖屏单手的 3D 农场解谜游戏原型。田里种着彩色像素画一样的作物，点一下车库里的收割机，它就沿着田边的环形小路开一圈，路过每一行、每一列时，把最外面那颗**同色**作物收走。装满就开回谷仓；没装满就停进等候位，之后可以再派出去。把整块田收干净就过关。

玩法借鉴了「传送带收集」类游戏（Pixel Flow 等），但换成了农场场景，并针对这类游戏常被吐槽的地方做了改良（见下方「改良点」）。

当前是**原型**：规则、关卡和 3D 画面都能玩，画面全部由代码生成的圆角积木组成（Overcooked 式的玩具风），还没有正式模型、音效和广告。

## 怎么运行

1. 安装 [Unity Hub](https://unity.com/download)，再通过 Hub 安装 **Unity 6**（勾选 Android Build Support）。
2. Unity Hub → Add → Add project from disk，选择这个文件夹。第一次打开需要几分钟导入。
3. 打开后直接点上方的 ▶ Play。即使是空场景，游戏也会自动生成画面。
4. 在 Game 窗口左上角把分辨率改成竖屏（例如 1080x1920），效果更接近手机。

想装到 Android 手机上：File → Save 把当前场景存为 `Assets/Scenes/Main.unity`，在 File → Build Profiles 里加入这个场景，切换到 Android 平台，连接手机后点 Build And Run。

## 玩法规则

- **点**车库里某条车道最前面的收割机（或等候位上的收割机），它就开出去绕田一圈。
- 路线：从左下角出发，沿下边从左到右 → 右边从下到上 → 上边从右到左 → 左边从上到下。
- 每到一行或一列，只看这条线上**最外面**的那颗作物：同色就收走，容量减 1；不同色就跳过。
- 容量减到 0 → 收割机开回谷仓。一圈结束还有容量 → 停进空的等候位。
- 收割机要停车但等候位全满 → 失败。整块田收完 → 过关。
- 一圈收 5 颗以上会出 Combo。

## 改良点（相对同类游戏）

- **按住预览**：按住收割机不放，会高亮这一圈会收走哪些作物、会不会装满或停车，松手不出发。
- **免费撤销**：每关 3 次，失败后也能撤销。
- **合并道具**：每关 1 次，把等候位上同色的收割机合成一辆，腾出车位。
- **失败不弹插屏广告**：失败界面只有「+1 等候位」（以后接激励视频，自愿观看）、撤销和重试。
- **点击可以连点排队**：前一辆还在跑，就能继续派下一辆，等在路边按顺序出发。
- **难度曲线平滑**：每关都由求解器验证能通关，并用「随机乱点的通关率」衡量难度。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `Assets/Scripts/Core` | 游戏规则（`HarvestState`）、关卡格式（`FieldLevel`）、求解器、关卡生成器。纯 C#，不依赖 Unity |
| `Assets/Scripts/Game` | Unity 画面和交互：`GameController`（流程和界面）、`World/FarmBoard`（3D 农场和动画）、`World/FarmKit`（作物、收割机、谷仓等积木模型） |
| `Assets/Editor` | 编辑器菜单：Harvest → Check All Levels / Reset Progress |
| `Assets/Tests/EditMode` | 单元测试（Window → General → Test Runner） |
| `Assets/Resources/Levels` | 关卡文件 `level_001.json` 起 |
| `tools/` | 不开 Unity 也能跑测试和生成关卡的脚本（需要 Mono） |

## 关卡格式

```json
{
  "id": 1,
  "name": "Heart",
  "bays": 5,
  "field": [".r.r.", "rrrrr", "rrrrr", ".rrr.", "..r.."],
  "lanes": ["r5 r4", "r3 r4"]
}
```

- 每个字母是一种作物：`r` 番茄、`g` 卷心菜、`b` 蓝莓、`y` 玉米、`p` 茄子、`o` 南瓜、`w` 菜花、`k` 小萝卜。`.` 是空地。
- `field` 是田地，从上到下一行一个字符串，像画像素画一样。
- `lanes` 是车道，每条车道的收割机从前到后排列，写法是「颜色字母 + 容量」。
- 每种作物的数量必须等于该颜色所有收割机容量之和。
- `bays` 是等候位数量。

## 不开 Unity 运行测试

需要 Mono（Ubuntu：`sudo apt install mono-mcs mono-runtime`），在项目根目录执行：

```bash
./tools/run-tests.sh     # 跑全部单元测试，包括检查每个关卡都能通关
./tools/gen-levels.sh    # 根据 tools/levelgen/Program.cs 里画好的田地重新生成关卡（几秒钟）
```

想加新关卡：在 `tools/levelgen/Program.cs` 里加一块像素画田地，再运行 `gen-levels.sh`。生成器会把每种作物拆成若干辆收割机、随机分到车道里，用求解器确认能通关，再挑难度最接近目标的一种。
